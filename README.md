# almanac-data

Data Preservation & Monitoring — open infrastructure mapping where authoritative public datasets live and whether they are still reachable

One domain per repo — health, climate,
economy, civics, energy, science, education, agriculture, justice,
transportation, environment — plus the
[template](https://github.com/almanac-data/almanac-template) they're
built from.

Local-first ethos: the data is yours to keep. No ports, no servers,
no subscriptions.
